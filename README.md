## About

I'm a Computer Engineering undergraduate at **Pune Institute of Computer Technology**, working at the seam between AI research and shipped software — the part where a capable model still has to survive latency budgets, CI pipelines, and real users.

- Currently building **VisionAI**, a distributed ML observability platform with a causal fairness engine and an agentic proxy that gates deployments
- Working in **LLM orchestration** with LangChain, LangGraph, Gemini, and Vertex AI — agentic systems rather than chat interfaces
- Previously interned at **Accenture** (Java Spring Boot, React) and **Cisco** (Python network automation over NETCONF/RESTCONF)
- **1st Prize** — Mastercard Code for Change · **Winner** — Inspiron 5.0 · **Top 10 Finalist** — Google Solutions Challenge
- Published two papers: *Impairment Assistance Software* (IRJMETS) and *Crop Yield Forecast Using Machine Learning* (IJASTR)
- **Amazon ML Summer School '26** · CS50x, CS50P, CS50 SQL — Harvard
- Open to conversations about agentic architectures, GCP Cloud Run, and inference reliability
