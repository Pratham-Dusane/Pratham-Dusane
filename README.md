## About

I'm a Computer Engineering undergraduate at **Pune Institute of Computer Technology**, working at the seam between AI research and shipped software — the part where a capable model still has to survive latency budgets, CI pipelines, and real users.

My interest sits in agentic architectures: systems where a language model isn't the product but a component inside one, with tool registries, evaluation harnesses, and failure modes that need engineering rather than prompting. Most of what I build ends up being infrastructure around the model rather than the model itself.

Open to conversations about agentic system design, GCP Cloud Run, and inference reliability.

## Currently Building

**SatQuery AI** — an agentic vision-language assistant for multimodal remote-sensing analysis, built against an ISRO/SAC problem statement and evaluated on benchmarks. Next.js and FastAPI over Google Earth Engine and hosted VLM APIs, with a tool registry, agentic controller, evidence layer, and evaluation harness. Currently extending it toward bitemporal and multitemporal scene comparison, layered annotation, and RAG over historical scenes.

**Trie-based autocomplete and spell check** — completions and corrections built from scratch on tries and supporting data structures, no NLP libraries and no external dependencies.

**Learning next:** inference optimization, distributed systems fundamentals, and the operational side of ML — the parts that make a working model dependable rather than merely correct.
